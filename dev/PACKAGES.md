# packages.json — ราคาแพ็กเกจจากร้าน

แอปโหลด `packages.json` (ราก repo) แสดงในข้อ 3 กล่อง "ราคาแพ็กเกจจากร้าน" เรียงตามบาท/kW กรองตามจังหวัดและขนาด
ว่าง (`"p": []`) = แสดง "กำลังรวบรวมราคา" · ทดสอบด้วย `dev/packages.example.json` (ข้อมูลสมมติ ห้ามขึ้นเว็บ)

ระดับบน: `at` วันที่อัปเดตไฟล์ (ค.ศ. YYYY-MM-DD), `p` รายการแพ็กเกจ

| key | ความหมาย |
|---|---|
| `src`, `vid` | `M`/`P` + id ร้านใน vendors.json (ใช้ดึงชื่อ เบอร์ อีเมล จังหวัดที่รับงาน และยืนยันว่าขึ้นทะเบียน) |
| `name` | ชื่อร้าน (ถ้าไม่ใส่ใช้จาก vendors.json) |
| `kw`, `phase`, `kwp` | ขนาดอินเวอร์เตอร์ (5 / 7.5 / 10), เฟส, กำลังรวมฝั่งแผง |
| `price`, `vat` | ราคารวม (บาท), `true` = รวม VAT แล้ว |
| `panel` | `{brand, model, w, n, eff, warr}` วัตต์ต่อแผง จำนวน ประสิทธิภาพ % ประกันสินค้า (ปี) |
| `inv` | `{brand, model, kw, warr}` |
| `warr` | `{work, fire, clean}` ประกันงาน / อัคคีภัย / ล้างแผง (ปี) |
| `std`, `bg` | ใช้สัญญามาตรฐาน, ให้หนังสือค้ำ 50,000/10,000 |
| `survey` | ค่าสำรวจ (บาท, 0 = ฟรี) |
| `serve` | `"*"` หรือ `["จังหวัด", ...]` (ไม่ใส่ = ใช้จาก vendors.json) |
| `includes`, `excludes`, `pay` | รวม / ไม่รวมอะไร, งวดจ่ายเงิน (ข้อความ) |
| `img` | รูปแพ็กเกจของร้าน (path ใน repo เช่น `assets/pkg/P00057-5kw.jpg` อัตราส่วน 4:3 กว้าง ≤960px) ใช้เฉพาะรูปที่ร้านส่งมาและอนุญาต ไม่มี = แสดงช่อง "ยังไม่มีรูปแพ็กเกจ" |
| `net` | ยอดจ่ายจริงหลังหัก 50,000 ตามที่ร้านแจ้ง (ถ้ามี ใช้ตัวเลขร้านแทนสูตร ราคา − 50,000) |
| `video` | ลิงก์วิดีโอของร้าน (https เฉพาะ facebook.com / fb.watch / youtube.com / youtu.be / tiktok.com) แสดงปุ่ม "▶ ดูวิดีโอ" และช่องรูปกลายเป็นพรีวิว แตะแล้วเล่นในการ์ด (FB plugin / YouTube / TikTok embed) · ลิงก์ FB แบบ /share/ อาจเล่นในการ์ดไม่ได้ ควรใช้ลิงก์เต็ม facebook.com/reel/… |
| `date`, `via`, `note` | วันที่ร้านแจ้งราคา, ช่องทาง (อีเมล/LINE/โทร), หมายเหตุ |

แอปแสดงหมายเหตุ (ไม่ใช่ป้ายเตือน) ถ้าเกิน 140,000 ชุด 5 kW · แอปเตือนเอง: แผงนอก 5–10 kWp, แผง <600 W, อินเวอร์เตอร์ประกัน <10 ปี, ประกันงาน/อัคคีภัย/ล้างแผง <7 ปี, ไม่ใช้สัญญามาตรฐาน, ไม่รวม VAT
ปุ่ม "ใส่ในตารางเทียบ" เติมลงตารางเทียบใบเสนอราคาช่องที่ว่าง

## ก่อนลงราคาร้าน (กฎ 1 พ.ย. 69)
- ต้องมีข้อความยินยอมจากร้านชัดเจน ("ลงได้" / "อนุญาต") เก็บภาพแชตไว้ ไม่นับคำตอบอ้อมๆ
- ตรวจตัวตน: เทียบชื่อบริษัท เบอร์ อีเมล กับ `vendors.json` (ทะเบียนการไฟฟ้า) และเบอร์บนเพจหลักของร้าน ถ้าเบอร์/ชื่อไม่ตรง ให้สงสัยไว้ก่อน ห้ามลงจนครูโบ้มยืนยัน
- ช่องติดต่อในการ์ดใช้เบอร์/อีเมลจาก `vendors.json` หรือเพจหลักเท่านั้น ไม่ใช้เบอร์ที่แอดมินแชตส่งมาถ้าไม่ตรงกัน
- การ์ดแสดง "จ่ายจริงราว (ราคา − 50,000)*" อัตโนมัติ ถ้าตัวเลข "จ่ายจริง" ที่ร้านแจ้งไม่ตรงสูตรนี้ ให้ถามร้านก่อน
