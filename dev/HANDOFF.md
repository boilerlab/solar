# แอป "ติดโซลาร์ภาคประชาชน คุ้มไหม?" — สรุปส่งต่องาน (Handoff)

อัปเดต: 28 ต.ค. 2569 · เจ้าของ: ครูโบ้ม (Boiler Lab, bike7day@gmail.com)

## 1. แอปคืออะไร
แอปเว็บฟรีหน้าเดียว ช่วยคนที่สนใจโครงการโซลาร์ภาคประชาชน 2569 (รัฐสนับสนุน 50,000 บาท/ราย) ตอบ 3 คำถาม:
1. **คุ้มไหม?** ใส่ค่าไฟ/เดือน แล้วจอแสดงผล คุ้ม / พอไหว / ยังไม่คุ้ม พร้อมเงินเหลือต่อเดือน
2. **พื้นที่พอไหม?** ใส่ขนาดหลังคา เลือกทรงหลังคาและแบบวางแผง หรือวางแผงบนภาพดาวเทียม
3. **ติดกับใคร?** ปุ่มลงทะเบียน PEA/MEA, ขอใบเสนอราคาจากร้านใกล้บ้าน (อีเมล/โทร/LINE), เงื่อนไขหลัก, เช็คลิสต์อุปกรณ์, ตารางเทียบใบเสนอราคา 3 เจ้า

ยังมีเมนูตัวเลขละเอียดสำหรับช่าง และคู่มือ/คำอธิบายท้ายหน้า

## 3. วิธีพัฒนาต่อ (workflow)
1. แก้ `dev/index.src.html` ซึ่งเป็นไฟล์ HTML เดียว มี CSS และ JS อยู่ในไฟล์ ไม่มี `<!doctype>` เพราะ build จะเติมให้
2. รัน `python3 dev/build-host.py` (ปรับ path ในสคริปต์ให้ตรง) จะได้ `index.html` ที่มี head เต็มและ Cloudflare beacon
3. ทดสอบด้วย Playwright (`require('playwright')`) ที่จอ 390×900 ก่อนทดสอบให้ `localStorage.clear()` แล้ว reload และ route ปิด URL ภายนอก
   - ทดสอบภาพดาวเทียม: ใช้ local http server ที่ส่ง `window.SOLAR_CONFIG={gmapsKey:'TEST'}` และ route `staticmap` ไปที่ภาพทดสอบ
4. Commit แล้ว push ไป `boilerlab/solar` main (user `boilerlab`)
5. Copy `index.html` และ `vendors.json` ไป `D:\Works\Solar_Design_System\host\` และทำ `solar-calculator.html` = `<!doctype html><meta charset="utf-8">` + source

## 5. ข้อมูลโครงการที่แอปใช้ (ณ 27–28 ต.ค. 69)
แหล่ง: เว็บ MEA/PEA, ข่าว The Standard/ฐานเศรษฐกิจ, **ร่าง**คู่มือ Vendor (เล่ม 2) และ**ร่าง**คู่มือประชาชน (เล่ม 1) ของมหาดไทย ลงวันที่ 27 ต.ค. 69 ทั้งสองเล่มเขียนว่า "เป็นร่างเพื่อพิจารณา ยังไม่บังคับใช้"

- **ระยะเวลา:**
  - ลงทะเบียน 27 ต.ค. 69 – 31 ม.ค. 70 (ThaID หรือบัตรประชาชน + บิลค่าไฟ, CA, เลขมิเตอร์)
  - ยื่นขอเชื่อมต่อภายใน 31 ส.ค. 70 และเชื่อมต่อเสร็จภายใน 30 ก.ย. 70
- **เงื่อนไขผู้ขอสิทธิ:**
  - คนไทย บุคคลธรรมดา มิเตอร์ประเภท 1 ชื่อตรงเจ้าของมิเตอร์ ใช้สิทธิ์ได้ครั้งเดียว
  - ติด **5–10 kWp ต่อมิเตอร์** (วัดฝั่งแผง)
- **ผู้ติดตั้ง:** ต้องเป็น MEA, PEA หรือร้านที่ขึ้นทะเบียน และ **ต้องใช้สัญญามาตรฐานของการไฟฟ้า** ถ้าไม่ใช้จะไม่ได้เงินสนับสนุน
- **เอกสารและสิทธิ์ซ้อน:**
  - ใบกำกับภาษีลงวันที่ ≥ 27 ต.ค. 69
  - ใช้คู่กับสิทธิ์ลดหย่อนภาษี (พ.ร.ฎ. 805) ไม่ได้
  - ผู้ถือบัตรสวัสดิการต้องสละส่วนลดค่าไฟ 20 ปี
  - ต้องมีพร้อมเพย์ผูกเลขบัตรประชาชน
- **ราคากลาง:** ชุด 5 kW 1 เฟส 140,000 บาท รวม VAT รวมประกันงาน 7 ปี ประกันอัคคีภัย 7 ปี ล้างแผงปีละครั้ง 7 ปี
  - ใช้กับหลังคาที่พร้อมติดตั้ง ถ้าต้องเสริมหลังคาหรือแก้ระบบไฟ ร้านต้องแยกรายการให้เราเห็นชอบก่อน
- **สเปกขั้นต่ำ:**
  - แผง ≥600 W ประสิทธิภาพ ≥21% ประกันสินค้า 10–12 ปี (เล่ม 1 เขียน 10 ปี เล่ม 2 เขียน 12 ปี) กำลังผลิต ≥80% ที่ 25 ปี
  - อินเวอร์เตอร์ขึ้นทะเบียน ≥5 kW 1 เฟส ประกัน ≥10 ปี
- **บริการหลังการขาย:** ตอบภายใน 24 ชม. เข้าตรวจภายใน 7 วัน แก้ไขเสร็จภายใน 15 วัน
- **หลักประกันที่ร้าน "ให้ลูกค้า" (Bank Guarantee):**
  - 50,000 บาท: ถ้าร้านส่งมอบไม่ทันภายใน 6 เดือนนับจากวันทำสัญญา ลูกค้ายึดได้
  - 10,000 บาท: ค้ำการดูแลหลังการขายตลอด 7 ปี
  - ค่าปรับร้านส่งมอบช้า 0.1%/วัน ของค่าจ้าง
- **การจ่ายเงิน:**
  - จ่ายสด: ลูกค้าจ่ายร้านเองก่อน แล้วรัฐโอน 50,000 เข้าพร้อมเพย์
  - กู้: ธนาคารจ่ายร้าน และ 50,000 เข้าธนาคารตรง
  - รัฐเบิกจ่ายภายใน **31 ธ.ค. 70**
  - สินเชื่อจาก ออมสิน / ธอส. / ธ.ก.ส. ราว 2.5% 7 ปี อนุมัติตามเกณฑ์ธนาคาร (ข่าวบอกว่าไม่เช็คเครดิตบูโร) ผ่อนผ่านบิลค่าไฟ
- **ขายไฟ:** ไม่เกิน 5 kW AC ต่อราย 2.20 บาท/หน่วย ต้องสมัครแยก เปลี่ยน Smart Meter ฟรี
- **ช่องทางติดต่อ:** MEA 1130, PEA 1129, ศูนย์ดำรงธรรม 1567

## 6. ทิศทางใหม่ (28 ต.ค. 69) — งานหลักถัดไป
ครูโบ้มเปลี่ยนจุดเน้นของแอป: **ไม่เน้นคำว่า คุ้ม/ไม่คุ้ม แล้ว** แอปจะพาคนไป **ลงทะเบียนรับสิทธิ** แล้วพาคนที่ได้สิทธิแล้ว **ไปเจอร้าน (vendor)** และขอใบเสนอราคาได้
- ปรับลำดับและข้อความในแอปให้เป็นเส้นทาง: เช็คสิทธิ → ลงทะเบียน (PEA/MEA) → ได้สิทธิแล้ว → เลือกร้านใกล้บ้าน → ขอ/เทียบใบเสนอราคา → ทำสัญญามาตรฐาน → ติดตั้งและเชื่อมต่อ → รับเงิน 50,000
- จอ CRT และผลคุ้ม/ไม่คุ้มลดบทบาทลง (เช่น ย้ายไปเป็นข้อมูลประกอบ หรือแสดงเป็น "ค่าไฟลดได้ราว ... บาท/เดือน")
- **ราคาแพ็กเกจมาตรฐานจากร้าน:** ครูโบ้มจะส่งอีเมลขอราคาชุดมาตรฐาน 5 kW on-grid (และ 7.5 / 10 kW ถ้ามี) จากร้านที่ขึ้นทะเบียน เพื่อนำมาแสดงเทียบในแอป ต้องออกแบบที่เก็บข้อมูล (เช่น `packages.json`: ร้าน, ขนาด, ราคารวม VAT, ยี่ห้อ/รุ่น/จำนวนแผงและอินเวอร์เตอร์, ประกันต่างๆ, จังหวัดที่รับงาน, วันที่ราคา, ราคานี้รวม/ไม่รวมอะไร) และหน้าแสดงเทียบ โดยระบุวันที่ของราคาและว่าเป็นข้อมูลที่ร้านแจ้งเอง

## 6.2 เส้นทางใหม่ (ทำแล้ว 28 ต.ค. 69)
- หน้าแรก (ข้อ 1) คงผลคุ้ม/ไม่คุ้มไว้เหมือนเดิม แล้วเพิ่มกล่อง `#rights` "เช็คสิทธิ์และลงทะเบียน": ติ๊ก 6 ข้อ (`#elig`), ปุ่ม PEA/MEA (ปุ่มที่ตรงจังหวัดจะกะพริบส้ม), สิ่งที่ต้องเตรียม, ตัวเลือกสถานะ 3 ขั้น `[data-rstat]` (ยังไม่ลงทะเบียน / ลงทะเบียนแล้ว รอผล / ได้สิทธิ์แล้ว) และปุ่ม `#rNext` ไปข้อ 3
- สถานะเก็บใน localStorage `solarRights` `{stat, el}` **ไม่มีวันหมดอายุ** (ต่างจาก solarState1 ที่เก็บ 12 ชม.) ปุ่มเริ่มใหม่จะล้างค่านี้ด้วย ถ้าได้สิทธิ์แล้ว แท็บ 3 จะกะพริบ
- แถบเส้นทาง 8 ขั้น `[data-path]` (`PATH`, `renderRights()`) แสดงทั้งในข้อ 1 และข้อ 3
- ข้อ 3 เปลี่ยนชื่อเป็น "เลือกร้าน" มีลำดับคือ `#gate` → `#pkgPanel` ราคาแพ็กเกจ → เลือกร้านที่ขึ้นทะเบียน → ขอใบเสนอราคา → เทียบใบเสนอราคา → เงื่อนไข/อุปกรณ์ → `#afterPanel` ทำอะไรต่อ (สัญญา → ติดตั้ง → เชื่อมต่อ → BG 10,000 → รับเงิน)
  - ส่วน `.afterR` ซ่อนไว้จนกว่าสถานะเป็น "ได้สิทธิ์แล้ว" หรือกด "ขอดูร้านและราคาไปก่อน" (`peek`)
- `packages.json` (ราก repo, ตอนนี้ยังว่าง) รูปแบบอยู่ใน `dev/PACKAGES.md` ตัวอย่างสำหรับทดสอบอยู่ใน `dev/packages.example.json` (ข้อมูลสมมติ ห้ามขึ้นเว็บ)
  - `pkgRender()` กรองตามจังหวัดและขนาด เรียงตามบาท/kW เตือนเรื่องสเปก ปุ่ม "ใส่ในตารางเทียบ" เติมข้อมูลลงตารางเทียบ
  - ทุกครั้งที่ sync ต้อง copy packages.json ไป `D:\Works\Solar_Design_System\host\` ด้วย

## 6.0 งานค้าง / ไอเดียถัดไป
1. ✅ **ใส่ข้อมูลจากร่างคู่มือประชาชน (เล่ม 1) แล้ว** (28 ต.ค. 69, commit 54ee4f0) ในข้อ 3:
   - เงื่อนไขหลัก: พร้อมเพย์ผูกบัตรประชาชน, เงิน 50,000 เบิกจ่ายภายใน 31 ธ.ค. 70, ลงทะเบียนแล้วยังไม่ใช่การรับรองว่าได้เงิน, กล่องพับ "เหตุที่อาจถูกปฏิเสธ/เรียกเงินคืน" (บทที่ 10 + คืนพร้อมดอกเบี้ย)
   - เลือกผู้ติดตั้ง: ต้องใช้สัญญามาตรฐาน, ขอ Bank Guarantee 50,000/10,000 (สิทธิ์ลูกค้า), ค่าสำรวจ (ถ้ามี), ประกันงาน 7 ปี (เดิมเขียน 1–2 ปี)
   - อุปกรณ์: ใบเสนอราคาต้องมีประมาณการผลผลิตพร้อมสมมติฐาน + วันติดตั้งเสร็จ, ประกันแผง 10 vs 12 ปี
   - ข้อความขอราคา เพิ่มข้อ 5–7 · ตารางเทียบราคาเพิ่มช่อง `std` (สัญญามาตรฐาน) และ `bg` (หนังสือค้ำ) พร้อมคำเตือน
2. **แผงเสื่อม:** แอปยังใช้ 0.5%/ปี ส่วนเกณฑ์ใหม่คือ ≤1% ปีแรก แล้ว ≤0.4%/ปี
3. **ข้อ 1 คิดผลที่ S1.size (5 kW)** ไม่ได้คิดที่จำนวนแผงจริง (9 แผง = 5.58 kWp) ถ้าเปลี่ยน ตัวเลขจะดีขึ้นราว 10%
4. **รายชื่อร้าน:** อัปเดตเป็นระยะ ดึงด้วยเบราว์เซอร์ในแอป Claude บนคอมผู้ใช้ (ได้สิทธิ์ site แล้ว)

   - PEA: API `https://peoplesolar.pea.co.th/api/backend/v1/vendors?page=N&pageSize=100` (มี `provinces` ที่ร้านรับงาน)
   - export เป็น JSON ลง Downloads แล้วรวมเป็น vendors.json
5. **ไอเดียที่คุยแล้ว ยังไม่ทำ:**
   - ลากแผงทีละแผ่นในกรอบข้อ 2

   - ตัวนับคลิกแบบ Cloudflare Worker ถ้าวิธี virtual path ไม่ขึ้น
   - ระบบรับคำขอใบเสนอราคาแบบมีเซิร์ฟเวอร์ (Cloudflare Workers + PDPA)
