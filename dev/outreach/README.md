# ส่งอีเมลขอราคาแพ็กเกจจากร้าน (งานรายวัน)

ไฟล์: `queue.json` (รายชื่อเรียงตามคะแนน), `email.md` (ข้อความ), `log.json` (ผลการส่งและการตอบ)
ผู้ส่ง: **boilerlabofficial@gmail.com เท่านั้น** · วันละ **30 ร้าน** · ส่งทีละร้าน (To: ไม่เกิน 2 อีเมลของร้านเดียวกัน) ห้าม BCC รวม

## ทุกวัน ทำตามลำดับนี้
1. ตรวจว่า Gmail ที่เชื่อมคือ boilerlabofficial@gmail.com (ดูผู้ส่งใน `in:sent`) ถ้าไม่ใช่ **หยุดทันที** แจ้งครูโบ้ม
2. อ่านอินบ็อกซ์ (`newer_than:2d` และเธรดที่ส่งไปแล้วใน log) แยกเป็น:
   - **ตอบราคา** → status `replied` สรุปตามรูปแบบ `../PACKAGES.md` ลง `pending` ใน log.json (ยังไม่แก้ packages.json) ระบุ `consent` true/false/unknown
   - **ไม่สนใจ / ขอเลิกรับ** → status `optout` ห้ามส่งอีก
   - **ตีกลับ (bounce)** → status `bounced`
   - คำถามจากร้าน → status `question` ไม่ต้องตอบเอง ให้สรุปให้ครูโบ้ม
3. ถ้าอีเมลตีกลับเกิน 20% ของที่ส่งเมื่อวาน หรือมีคำเตือนสแปมจาก Google → หยุดส่งวันนั้น แจ้งครูโบ้ม
4. ส่ง 30 ร้านถัดไปที่ `status: queued` ตามลำดับใน queue.json ตามข้อความใน email.md บันทึก `sent` (วันที่, threadId) ลง log.json
5. Commit log.json แล้ว push (`boilerlab/solar` main)
6. รายงานสั้น: ส่งกี่ร้าน, ตอบกี่ร้าน, ราคาที่รออนุมัติ, คำถามจากร้าน
**ห้ามแก้ packages.json เอง** ครูโบ้มต้องอนุมัติก่อน
